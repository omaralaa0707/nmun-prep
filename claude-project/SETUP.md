# The NMUN Interview Coach Project on claude.ai

## Files
1. **Instructions:** paste everything from `INSTRUCTIONS.md`.
2. **Project knowledge** (upload these; replace a file when it changes):
   - `01_un_core.md`
   - `02_question_bank.md`
   - `04_my_profile.md`
   - `05_mozambique_and_topics.md`
   - `06_study_hq.md` (plan, availability, tools, decisions)

## Use it on the phone
- **Mocks and voice quizzes:** open the Claude app → Projects → NMUN Interview Coach → new chat → tap the voice button and say the phrase from today's plan, e.g. "Full mock, 60 minutes. Include my country." Say "pause", "resume" and "end".
- **Planning:** in a new chat in the same Project, type e.g. "What should I do tonight?" or "I'm behind, re-plan Sunday".

## Changing the app or the Doc
The chat Project can't edit them. Use Claude Code on the web or the phone (claude.ai/code → repository `omaralaa0707/nmun-prep`): it reads `CLAUDE.md`, edits the files and pushes, and pushing to `main` deploys the app automatically. After it changes unit content or the plan, it regenerates the files here and tells you which ones to re-upload.

## After each mock
Add the suggested line to the session log in `04_my_profile.md`, then replace that file in Project knowledge.
